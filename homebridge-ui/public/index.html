Adding Apple Remote to Home

Enable “TV accessory and Apple Remote” for a zone, save, then restart its Homebridge instance or child bridge.

In Apple Home, select Add Accessory → More options and pair the zone’s TV accessory. The separate Power, Volume, and Mute switches appear automatically when enabled.

Use Homebridge’s Save button to keep your changes, then restart the Homebridge instance or child bridge running this plugin.
